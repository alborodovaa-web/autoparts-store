# Интернет-магазин автозапчастей

## 1. Описание проекта

Backend-приложение интернет-магазина автозапчастей. Проект предназначен для управления товарами, пользователями, корзиной и заказами.

Приложение предоставляет REST API для взаимодействия с данными и поддерживает разграничение доступа по ролям пользователей.

## 2. Используемые технологии

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- Gradle
- Hibernate
- REST API

## 3. Основные возможности

- Регистрация и авторизация пользователей.
- Просмотр, поиск и фильтрация товаров.
- Управление товарами.
- Просмотр категорий и брендов.
- Добавление и удаление товаров из корзины.
- Изменение количества товаров в корзине.
- Оформление и просмотр заказов.
- Изменение статусов заказов.
- Управление пользователями и их ролями.
- Разграничение доступа для CLIENT, EMPLOYEE и ADMIN.

## 4. Требования для запуска

Перед запуском необходимо установить:

- JDK 21.
- PostgreSQL.
- IntelliJ IDEA (или другую среду разработки с поддержкой Java).
- Git (при необходимости работы с репозиторием).

## 5. Настройка базы данных

1. Установить и запустить PostgreSQL.
2. Создать базу данных с названием `autoparts-store`.
3. Настроить переменные окружения:

| Переменная | Значение |
|---|---|
| DB_USERNAME | Имя пользователя PostgreSQL |
| DB_PASSWORD | Пароль пользователя PostgreSQL |

Параметры подключения задаются в файле `application.properties`.

По умолчанию используется адрес базы данных:

`jdbc:postgresql://localhost:5432/autoparts-store`

Hibernate автоматически обновляет структуру таблиц при запуске приложения.

## 6. Запуск приложения

1. Скачать или клонировать репозиторий.
2. Открыть проект в IntelliJ IDEA.
3. Указать JDK 21.
4. Создать базу данных и настроить переменные окружения.
5. Запустить главный класс `AutopartsStoreApplication`.

Также приложение можно запустить через Gradle Wrapper в терминале Windows:

`.\gradlew.bat bootRun`

После успешного запуска приложение будет доступно по адресу:

`http://localhost:8080`

## 7. Проверка API

Для проверки REST API можно использовать Postman.

Основные группы запросов:

- `/users` — пользователи и авторизация.
- `/products` — товары.
- `/categories` — категории.
- `/brands` — бренды.
- `/cart` — корзина.
- `/orders` — заказы.

## 8. Структура проекта

- `config` — конфигурация приложения и безопасности.
- `controller` — обработка HTTP-запросов.
- `dto` — объекты передачи данных.
- `entity` — сущности базы данных.
- `repository` — взаимодействие с базой данных.
- `service` — бизнес-логика приложения.
- `exception` — обработка ошибок.
